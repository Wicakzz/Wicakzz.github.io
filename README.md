# Portofolio Bagas Wicaksono

Website portofolio pribadi, dibangun dengan Next.js, TypeScript, dan Tailwind CSS.

## Menjalankan di lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Mengubah isi

Semua konten (profil, keahlian, project, riwayat, kontak) ada di `src/data/profile.ts`.
Gambar dan CV disimpan di folder `public/`:

- `public/cv.pdf` untuk CV
- `public/profile.jpg` untuk foto profil 
- `public/projects/*.png` untuk screenshot project
